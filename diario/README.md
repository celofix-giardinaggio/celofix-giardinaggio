# 📔 Diario digitale del giardino

Questa cartella raccoglie le attività e le osservazioni del progetto **Celofix Giardinaggio**.

## Come usare il diario

- Crea un file per ogni giornata di attività, usando il formato `AAAA-MM-GG.md` (esempio: `2026-10-25.md`).
- Parti da `PLANTILLA.md` e copia la struttura nel nuovo file.
- Annota solo ciò che hai fatto o osservato davvero. Se un dato non è noto, scrivi “da verificare”.
- Per le piante, indica il nome comune se lo conosci; il nome scientifico è facoltativo.
- Evita indirizzi privati, dati personali e foto di persone senza consenso.
